# デモ動画 (kilde-site#1) 制作パッケージ

「会議を録って、文字起こしと要約まで」を 60 秒で見せる動画の制作に必要なものを
ここにまとめてある。**動画ファイルそのものは未制作** — このパッケージは
撮影・編集・公開を遂行するための台本と素材。収録には実機と画面収録の権限が要るため、
撮影と編集は依頼者が行い、完成したファイルをこのリポジトリに置いて埋め込む。

## ファイル

| ファイル | 内容 |
|---|---|
| [storyboard.md](storyboard.md) | 絵コンテ (60 秒版 + App Store プレビュー 30 秒版)。撮影と編集の正本 |
| `captions/demo-ja.vtt` / `demo-en.vtt` | Web 公開用の字幕 (HTML `<track>` で使用) |
| `captions/demo-ja.srt` / `demo-en.srt` | 編集ソフト用の字幕 (Premiere / DaVinci 等に読み込み) |

## 制作手順

1. **準備** — 下の収録チェックリストを通す。テスト音声は
   `say -o meeting-ja.aiff "台本"` で作る (台本は README 末尾)
2. **収録** — 絵コンテの beat 1〜7 を通しで撮る (1 take でなくてよい。
   編集でつなぐ前提のほうが撮りやすい)。Stop の瞬間は 2 回撮っておくと安全
3. **編集** — 60 秒版を組み、字幕 (SRT) を読み込む。
   その後、App Store 30 秒版を絵コンテの配分で別書き出し
4. **書き出し** — MP4 (H.264)、1920×1080 / 30fps。
   サイト掲載版の目安は **8 MB 以下** (モバイル回線を想定。超えるなら
   ビットレートを下げるか、クロップで無駄な画面を削る)
5. **公開** — 下の「埋め込み計画」に従ってトップページに載せる (別 PR)

## 収録チェックリスト

- [ ] kilde を最新版に更新した (文字起こし・要約・検索が載っている版)
- [ ] 画面収録・マイクの権限が通っている (`kilde doctor` で確認)
- [ ] **実在の会議サービスのロゴ・ウィンドウ名を映していない**
      (App Store 審査対策 — issue #1 のスコープ)。会議の「相手」は
      say で作った音声 + タイトルだけの汎用ウィンドウで表現
- [ ] ほかのメニューバーアイコンを隠した (個人ファイル名・サービス名が
      見えるアイコンを映さない)
- [ ] 通知を集中モードで止めた (画面にバナーが出ない)
- [ ] デスクトップに個人ファイルを映していない (背景を単色にするのが早い)
- [ ] 1920×1080 / 30fps で収録した
- [ ] 文字起こし・要約・検索は静止画ではなく**実機の動作**を撮った

## 埋め込み計画 (動画完成後の別 PR で実施)

サイトは JavaScript を使わない方針なので、遅延読み込みは
`preload="none"` + poster 画像で試みる (JS 追加はしない)。ただし
`preload` はブラウザへのヒントで、事前読み込みを完全には防げないため、
これはベストエフォートである。公開後にモバイルブラウザでの転送量を
実測して、受け入れ条件 «モバイルでも読み込みが重くない» を判定する:

```html
<video controls preload="none" poster="/assets/demo/demo-poster.jpg"
       width="960" height="540">
  <source src="/assets/demo/demo-60s.mp4" type="video/mp4">
  <track kind="subtitles" src="/assets/demo/demo-ja.vtt" srclang="ja" label="日本語" default>
  <track kind="subtitles" src="/assets/demo/demo-en.vtt" srclang="en" label="English">
</video>
```

- 配置: `public/assets/demo/` (mp4 / poster / vtt)。字幕は**このリポジトリの
  captions/*.vtt をコピー**する (サイトから編集用 SRT は配信しない)。
  絵コンテのとおり収録後に SRT の時刻を調整したら、**同じ時刻を VTT にも
  反映してから**コピーする — このリポジトリの captions は撮影前の初期版で、
  そのままコピーすると完成動画とずれる
- トップページ (日英両方) の features セクション直後に 1 箇所。
  日本語トップは ja 字幕を default、英語トップは en 字幕を default にする
- poster は動画の冒頭フレーム (締めカードではなく操作が見えるフレーム) から
  作る。サイズ目安 100 KB 以下
- robots / sitemap への追加は不要 (動画はページの一部で、独立ページを作らない)

## デモ音源の台本 (say)

会議の「相手」の音。**撮影中にスピーカーから鳴らして**、システム音声として録る。
日本語版は Kyoko、英語版は (実機にあれば) Samantha 等の英語ボイス。
`say -o` はファイルに書き出すだけで**再生しない** — 収録中は `afplay` で
鳴らすこと (収録前に書き出して確認し、本番で再生する二段構え)。

```sh
# 日本語 (進行同期の想定、約 15 秒)。先に書き出して確認する
say -v Kyoko -o meeting-ja.aiff \
  "進行同期を始めます。サイトの比較ページ、来週の月曜に公開します。"
say -v Kyoko -o meeting-ja-2.aiff \
  "デモ動画は私が撮ります。ほかに動きのある人、いますか。"

# 英語版の撮影用
say -v Samantha -o meeting-en.aiff \
  "Let's start the sync. The comparison page ships next Monday."

# 本番 (収録中): kilde が録り始めたらスピーカーで再生する
afplay meeting-ja.aiff
```

自分の声はマイクから実際に話す (「はい、デモ動画の絵コンテはできています」など、
字幕と内容がずれない短い返答 1〜2 回でよい)。
なお kilde 側の収録は**画面全体 + システム音声**で行う (絵コンテの
«共通の画面構成» 参照 — ウィンドウ収録にすると say の音が録れない)。

- [ ] モバイルでも読み込みが重くない → `preload="none"` + poster と
