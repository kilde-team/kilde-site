# デモ動画 絵コンテ (60 秒版 + App Store 30 秒版)

kilde-site#1 の撮影台本。**この表が撮影と編集の正本**で、字幕ファイル
(`captions/`) と時刻が対応しています。収録後に実写のラグに合わせて
字幕の時刻を微調整してよいが、秒数配分は変えない (App Store 版の切り出し地点がずれるため)。

## 共通の画面構成

- 画面は 1920×1080 / 30fps。メニューバーの kilde アイコンとポップオーバーが主役。
  ほかのメニューバーアイコンは撮影前に隠す (プライバシーと審査対策 — README 参照)
- ナレーションは付けない。**字幕で伝える** (issue の «字幕差し替えでも可» 方式。
  日英は字幕ファイルの差し替えだけで作れる)
- デモの「会議」は実在サービスを使わない: テキストエディタの書類
  «進行同期メモ» を画面に置き、`say` コマンドで作った会議風の音声を
  スピーカーで再生する (台本は README)。自分の声はマイクで実際に話す

### Product Hunt / Show HN への流用

- Product Hunt のギャラリーには 60 秒版をそのまま使う
  (字幕は英語版を選択。日本語版は kilde.site の日本語トップ用)
- Show HN は本文の最初に 60 秒版を貼る (docs/launch/show-hn.md の指定どおり)

## 撮影上の注意 (審査と品質)

- **実在の会議サービスのロゴ・ウィンドウ名を映さない** (issue の審査対策スコープ)。
  会議の「相手」は say 生成の音声と、タイトルを付けただけの汎用ウィンドウで表現する
- 通知は集中モードで止める (字幕と競合するバナーが出ないように。音は kilde 側の
  アプリ スコープでも防がれるが、画面のバナーは撮影で見える)
- テキストが読めるサイズを保つ: ポップオーバーは 1080p で小さくなりすぎる場合、
  画面の一部をクロップして編集で拡大してよい (等倍を保つこと)
- 文字起こしと要約は**実機の動作**を撮る。演出の代打の静止画を差し込まない
  (「必ずファイナライズ」の訴求と整合させるため)
- 収録前に kilde を最新版に更新し、UI の文字列と字幕の表記を突き合わせる
  (この絵コンテは機能を説明するもので、UI の正確なラベルを引用していないため)
