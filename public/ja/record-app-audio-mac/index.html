会議アプリの音だけを録る

アプリに絞った音声収録 — ドライバの追加インストールは不要

やりたいことはひとつ: 録画ファイルには会議アプリの音 — 参加者の声 — だけが 入っていて、デスクトップのほかの音は入っていてほしくない。ところが、ふだんのシステム音声収録は Mac が再生しているすべての音を拾います。通知のチャイム、音楽、別のウィンドウの 動画も。kilde は録音の音声を 1 つのアプリに絞る方法を 2 つ持っています。 音声がそのアプリに紐づくウィンドウ収録と、macOS 15 以降で使える実行中アプリの音声を 直接収録する方法です。仮想オーディオドライバは不要です。

デスクトップ全体の音声収録は、欲しくない音まで入る

一般的なシステム音声の収録は、Mac から出る音をすべて録ります。あとで議事録や 文字起こしにするつもりの会議録音では、漏れ出てくるのはまさに要らなかった音 — 発言の途中に鳴る カレンダーのリマインダー、チャットの通知音、別アプリで再生しっぱなしだった音です。声はファイルに 入っています。それ以外の音も、一緒に。

手動でミュートして回るのは脆いやり方です。覚えていたアプリは消せても、忘れた 1 つが鳴ってしまいます。 本当に欲しいのは「このアプリの音だけ」と指差して指定することです。

方法 1: ウィンドウを収録すると、音声もそのアプリに絞られる

kilde rec --no-video --window zoom 会議.m4a

--window はウィンドウをタイトルの部分一致・bundle ID・ウィンドウ ID で指定します (kilde devices で一覧できます)。選んだウィンドウだけを収録し、システム音声も そのウィンドウのアプリの音だけに絞られるため、通知音もほかのアプリの音も入りません。 メニューバーアプリなら収録対象として会議のウィンドウを選ぶだけで、同じ絞り込みが効きます。 この方法は macOS 14 以降で使えます。

方法 2: 実行中アプリの音を直接収録する (macOS 15+)

kilde rec --no-video --audio app:zoom --audio mic 会議.m4a

macOS 15 以降では --audio app: で、実行中のアプリの音声を直接 収録できます。指定は名前の部分一致か、bundle ID の完全一致 (大文字小文字は区別しない) です。 上の例ではマイクを並べて収録しており、--audio-tracks separate を付けると ソースごとにトラックを分けられます。知っておくべき点が 2 つあります。--audio system とは併用できないこと、そして指定したアプリを解決できなかったときはシステム音声へ静かにフォールバック せず録画の開始前に失敗すること — 気づくのが会議の後ではなく、録る前です。 メニューバーアプリでも音声ソースとしてアプリ別の音声収録を選べます (macOS 15 以降で表示される オプションです)。

録るのが会議なら

アプリに絞った音声収録は、会議の録画にぴったりの組み合わせです。参加者の声と自分のマイクを 1 本のファイルに混ぜるところまで含めた手順は オンライン会議の録画ガイド で解説しています。

録った音を議事録へ

macOS 26 以降では、録画をこの Mac の中だけで文字起こしできます (音声も 書き起こしテキストも送信されません)。文字起こしは録画ファイルの隣に Markdown / SRT / WebVTT / テキスト / JSON で書き出され、Apple Intelligence が有効な環境では要約も作れます。 文字起こしも要約も端末内で完結し、現時点では無料で使えます。kilde 自体はオープンソース (MIT ライセンス) です。詳細は ボットなしの会議文字起こし をどうぞ。
