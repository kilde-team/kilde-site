プライバシーポリシー

最終更新日: 2026年9月25日

要点: kilde はお使いの Mac の中だけで動作します。録画したファイルはご自身の ディスクに書き出され、私たちにも第三者にも送信されません。文字起こし (macOS 26 以降) も Mac の中で完結し、音声も書き起こしテキストもどこにも送信されません。追加される通信は、 文字起こしする言語のモデルがまだ Mac に無いときの Apple からの言語モデルのダウンロード だけです (モデルはシステムが管理しており、しばらく使われないものは削除されることがあるため、 ダウンロードが再び起こることもあります)。 メニューバーアプリは Google の Firebase Analytics で起動回数やバージョンなどの匿名の利用統計を計測し、クラッシュしたときは Firebase Crashlytics でクラッシュレポートを送信します。録画の内容や設定は送信しません。kilde コマンドラインは言語モデルのダウンロードを除いて一切通信しません。本ウェブサイトはページビューの集計のために Google アナリティクスを利用していますが、Cookie を一切保存しない設定で 運用しており、再訪問した利用者を識別することはできません。

1. 本ポリシーの適用範囲

本ポリシーは、macOS 向けの OSS 画面 + 音声 録画ツール kilde および本ウェブ サイト (kilde.site) に関連する個人情報の取り扱いについて説明するものです。 対象は次の 2 つです。

  • ご自身の Mac にインストールして実行する kilde の CLI とメニューバーアプリ
  • いまご覧になっている本ウェブサイト

kilde は MIT ライセンス で配布されています。本ポリシーは kilde プロジェクトが公開しているソフトウェアについての 説明であり、ご自身でビルド・改変したもの、または第三者から入手したものについては、 ここに記載した挙動が当てはまらない場合があります。

2. kilde アプリケーション

録画の内容と設定は収集しません

kilde が録画の内容やあなたの設定を収集・送信・販売することはありません。 アカウント、サインイン、広告はいずれも存在せず、 通信先となる kilde のサーバーもありません。

文字起こしは Mac の中で完結します (macOS 26 以降)

文字起こし機能は、録画の音声をサイドカーファイル (markdown / SRT / VTT / テキスト / JSON) として録画ファイルと同じ場所に書き出します。処理は macOS に組み込まれた音声認識に より、すべてあなたの Mac の上 (オンデバイス) で行われます。

  • 録音した音声も、書き起こしたテキストも送信されません — kilde にも、 Apple を含む第三者にも送信されません。
  • 書き起こしテキストは、録画ファイルと同じ場所のサイドカーファイルにだけ書き込まれます。
  • Speech recognition 権限は別途必要ありません。
  • 文字起こしする言語の言語モデルがまだ Mac に無い場合、Apple からダウンロードします。 モデルはシステムが管理しており、しばらく使われないものは削除されることがあるため、 このダウンロードは再び起こることがあります。この通信でやり取りされるのはモデルそのものだけで、 音声やテキストは送信されません (一般的なネットワーク通信と同じく IP アドレスは Apple に 伝わります。取り扱いは Apple のプライバシーポリシーに従います)。

メニューバーアプリの利用統計

メニューバーアプリ (Mac App Store 版・直接配布版とも) は、アプリの利用状況を把握するために Google の Firebase Analytics を利用しています。バージョン 0.3.0 以前には含まれていません。

  • 送信されるもの: 起動回数や利用頻度、アプリのバージョン、macOS のバージョン、 デバイスの種類、IP アドレスから Google が推定する大まかな地域などの利用統計です。これらは Firebase が生成するランダムなアプリインスタンス ID に紐づけられますが、氏名・メールアドレス・ Apple ID・広告識別子ではありません。
  • 送信されないもの: 録画の内容 (映像・音声・ファイル名・保存先) と、 あなたの設定 (ホットキー・保存先・音声ソースなど)。
  • 取り扱い: データは Google のサーバーに送信され、 Google のプライバシーポリシーに従って 処理されます。開発者が見られるのは集計された統計のみです。広告機能は無効にしており、 広告には利用されません。
  • kilde コマンドラインには解析機能もクラッシュレポートもなく、Apple からの文字起こし言語モデルの ダウンロードを除き、何も送信しません。

メニューバーアプリのクラッシュレポート

メニューバーアプリ (Mac App Store 版・直接配布版とも) は、異常終了 (クラッシュ) したときに、 開発者が不具合を見つけて直すために Google の Firebase Crashlytics でクラッシュレポートを送信します。0.5.0 以前のバージョンには含まれていません。

  • 送信されるもの: クラッシュ時のスタックトレース (アプリのどこで落ちたか)、 アプリと macOS のバージョン、デバイスの種類、空きメモリ・ディスク容量などの端末状態、 クラッシュの日時、アプリのインストールごとに割り振られるランダムな ID。
  • 送信のタイミング: クラッシュした後、次にアプリを起動したとき。
  • 送信されないもの: 録画の内容、ファイル名、保存先、あなたの設定。
  • 取り扱い: レポートは Google のサーバーに送信され、 Google のプライバシーポリシーに従って 処理されます。開発者は不具合の修正のためにのみ利用します。

その他の通信

  • Mac App Store 版: 上記の利用統計とクラッシュレポートのほか、アップデートは App Store を通じて配信されます。
  • 直接配布版のメニューバーアプリ (GitHub Releases の kilde-<version>-macos.zip): アップデート確認のため、自動更新ライブラリ Sparkle が GitHub から更新情報を取得します。一般的な Web 通信と同じく IP アドレスやアプリのバージョンが GitHub に伝わりますが、開発者が受け取ることは ありません。自動確認を行うかどうかは Sparkle の確認ダイアログで選べます。
  • 文字起こし言語モデル (すべての配布形態、macOS 26 以降): 文字起こしは オンデバイスで処理されますが、言語のモデルがまだ Mac に無い場合に Apple から ダウンロードします。モデルはシステムが管理しており、しばらく使われないものは 削除されることがあるため、このダウンロードは再び起こることがあります。 やり取りされるのはモデルそのものだけで、音声やテキストは 送信されません (一般的なネットワーク通信と同じく IP アドレスは Apple に伝わります。取り扱いは Apple のプライバシーポリシーに従います)。
  • コマンドライン: 上の文字起こし言語モデルのダウンロードを除いて、ネットワーク通信を 行いません。Homebrew で入れた場合、更新は brew upgrade を実行したときだけ行われます。

Mac の中に保存されるもの

データ保存場所目的
録画・録音ファイル 指定した出力パス、または設定した出力ディレクトリ ツールの成果物そのものです。ローカルディスクに直接書き出されます。
設定 ~/.kilde/config.json (KILDE_CONFIG_DIR で変更可) 出力先・音声ソース・コーデック・ホットキーなど、録画の既定値の保持。
モニターモードの状態 同じディレクトリの monitor-state.json モニター録音の終了後にオーディオデバイス構成を元に戻すため。
メニューバーアプリの「最近の録画」 出力ディレクトリをその都度読み取り パネルに表示して Finder で開けるようにするためだけに使用し、どこにも複製しません。
文字起こしテキスト (macOS 26 以降) 録画ファイルと同じ場所のサイドカーファイル (markdown/SRT/VTT/テキスト/JSON) オンデバイスの文字起こし機能が書き出すものです。どこにも送信されません。

これらはすべて利用者の管理下にあります。ファイルを削除する、kilde config で 設定を変更する、~/.kilde ディレクトリを削除する、といった操作でデータは 端末から消えます。書き起こしテキストは録画ファイルとは別のサイドカーファイルなので、 録画を削除するときは必要に応じて一緒に削除してください。

録画には個人情報が含まれ得ます

画面や音声の録画には、そのとき映っていたもの・聞こえていたものがそのまま記録されます。 顔、声、氏名、書類、メッセージ、会議での他の参加者の発言などです。kilde がその内容を 参照・受信することはありませんが、ディスクに保存された時点で、その取り扱いの責任は 利用者ご自身にあります。録画前に法令や所属組織が求める同意を得ることも 同様です。詳しくは利用規約をご覧ください。

3. macOS の権限

キャプチャへのアクセスを制御しているのは kilde ではなく macOS です。kilde は必要な権限を システムに要求し、許可するかどうかは macOS が利用者に確認します。

  • 画面収録とシステムオーディオ — ディスプレイやウィンドウ、システム音声の収録に必要です。
  • マイク — マイクやその他の入力デバイスを録音する場合にのみ必要です。
  • 通知 — 任意。メニューバーアプリが録画の完了を知らせるために使用します。
  • ログイン時に起動 — 任意。メニューバーアプリで有効にしたときに Apple の SMAppService を通じて登録されます。

これらの権限は、利用者が指示した録画を実行する目的にのみ使用されます。権限はいつでも システム設定 → プライバシーとセキュリティで確認・取り消しができます。 現在の付与状況は kilde doctor で確認できます。

4. 本ウェブサイト

本サイトは静的なページのみで構成されています。Cookie を設定せず、 ローカルストレージにも書き込まず、広告の配信や外部フォントの読み込みもありません。

アクセス解析について

どのページが役に立っているかを把握するため、本ウェブサイトは Google アナリティクス 4 を読み込んでいます。プライバシーに配慮した以下の設定で運用しています。

  • クライアント側のストレージを無効化しているため、解析用の Cookie もローカルストレージも作成されません。
  • 識別子を持たないため、複数の訪問を結び付けたり、再訪問した利用者を特定したりすることはできません。
  • Google シグナル・広告機能・広告のパーソナライズはすべて無効化し、広告データのリダクションを有効にしています。取得した情報が広告目的で使われることはありません。
  • IP アドレスは Google 側で匿名化され、私たちが参照することはできません。
  • ブラウザが Do Not Track または Global Privacy Control のシグナルを送信している場合、スクリプト自体を読み込みません。

私たちが受け取るのは、ページの URL とタイトル、参照元サイト、IP アドレスから推定されたおおまかな 国や都市、端末の種別、ブラウザ、言語に加えて、ページをどこまでスクロールしたか、サイト外への リンクのクリック、リンクされたファイルのダウンロードといった操作の記録です。いずれも個人を 特定しない統計情報です。これらはドキュメントや サイトの改善方針を決めるためだけに利用し、販売したり広告目的で共有したりすることはありません。 Google による処理については Google のプライバシーポリシーおよび Google アナリティクスのデータ使用について をご参照ください。

解析を完全に停止したい場合は、ブラウザで Do Not Track や Global Privacy Control を有効にするか、 Google アナリティクス オプトアウト アドオン を導入するか、コンテンツブロッカーで googletagmanager.com をブロックしてください。 本サイトの機能は解析に依存していないため、ブロックしても表示や動作に影響はありません。

ホスティング

本サイトは Cloudflare でホスティングしています。 一般的なホスティング事業者と同様に、Cloudflare はページの配信とサービスの保護のため、 IP アドレス、リクエストされた URL、リクエスト日時、ブラウザのユーザーエージェントといった 技術的な情報を処理します。その取り扱いは Cloudflare のプライバシーポリシー に従います。私たちがこれらの情報を用いて訪問者を特定したり、プロファイリングすることは ありません。

また本サイトでは Cloudflare 自身の Web Analytics も稼働しており、 エッジ側でページビューを集計しています。Cookie を設定せず、クライアント側のストレージも 使わず、フィンガープリントやサイトをまたいだ追跡も行いません。取得されるのは上記と同様の 統計情報です。識別子を一切使わずにページビューを数えられるため、流入元などの内訳が分かる Google アナリティクスと併用しています。

5. 第三者サービス

kilde に関連して利用者が行う操作の一部は、それぞれ独自のプライバシーポリシーを持つ 他社のサービス上で行われます。

  • GitHub — ソースコード、リリース、Issue、ドキュメントは GitHub 上にあります。 リリースのダウンロード、Issue の作成、プルリクエストの送信は GitHub のプライバシーステートメント に従います。
  • Homebrew — brew でのインストールは GitHub からリリース成果物を ダウンロードします。Homebrew 自体の挙動 (アナリティクスを含む) は kilde ではなく Homebrew プロジェクトの定めるところによります。
  • Google アナリティクス — 本ウェブサイトのアクセス解析にのみ利用しており、 第 4 条に記載の Cookie を使用しない設定で運用しています。取り扱いは Google のプライバシーポリシーに従います。
  • Firebase Analytics (Google) — メニューバーアプリの匿名の利用統計の計測に 利用しています (第 2 条参照)。取り扱いは Google のプライバシーポリシーおよび Firebase のプライバシー情報に従います。
  • Apple — macOS 26 以降で、文字起こし機能は言語のモデルがまだ Mac に無い ときに Apple から言語モデルをダウンロードします (すべての配布形態)。音声と書き起こしテキストは 送信されません (第 2 条参照)。Apple 側の取り扱いは Apple のプライバシーポリシーに従います。

kilde プロジェクトがこれらのサービスから受け取る個人情報は、公開リポジトリの管理者が 通常見られる範囲 (利用者が自ら投稿した Issue やプルリクエストに紐づく GitHub アカウント名など) を超えるものではありません。

6. 利用者の選択と権利

録画の内容と設定は Mac の外に出ず、開発者が Firebase で見られる利用統計も集計値で個人に たどり着けないため、プロジェクト側に開示・訂正・利用停止・削除の対象となる個人情報は 保有していません。メニューバーアプリに利用統計を送らせたくない場合は、解析を行わない kilde コマンドラインを使うか (通信は文字起こし言語モデルのダウンロードのみ)、 ファイアウォールでアプリの外向き通信を遮断してください。 kilde が生成するデータは利用者ご自身の端末上にあり、 いつでも削除できます。ウェブサイトのアクセス解析は統計情報のみで、利用者にたどり着ける 識別子を含まないため、個別に照会できるデータは存在しません。収集そのものを停止したい場合は 第 4 条のオプトアウト手段をご利用ください。

GitHub の Issue などでプロジェクトに連絡した場合、その内容は公開され、リポジトリが 存在する限り GitHub に保持されます。投稿の削除を希望される場合は、同じ窓口でお知らせ ください。公開の Issue には機微な個人情報を記載しないようご注意ください。

7. お子さまの利用について

kilde は開発者向けのツールであり、お子さまを対象としたものではありません。お子さまを 含め、誰からも意図的に情報を収集することはありません。

8. 本ポリシーの変更

本ポリシーはソフトウェアの変更に伴い改定されることがあります。最新版は常に本ページに 掲載し、冒頭の最終更新日を更新します。重要な変更については GitHub のリリースノートでも お知らせします。

9. お問い合わせ

プライバシーに関するお問い合わせは github.com/kilde-team/kilde/issues の Issue としてお寄せください。
